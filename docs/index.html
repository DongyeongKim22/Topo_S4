Overview

Earlier Topo_S4 branches tried scalar PH-Sobolev forward masks and then learnable operator-level PH adapters. The current result is sharper: the PH module itself has no learnable parameters. It computes a reliable per-sample spectral residual and uses it to reweight the existing S4D/DFouT C residues.

DFouT = coverage

DFouT already places poles across the Fourier domain. The current question is not whether the model has high-frequency basis functions, but which of those modes should matter for a particular sample.

PH = stable support

H0 superlevel PH on log FFT magnitude behaves like a stable spectral peak detector. It returns persistent peaks plus connected support intervals rather than isolated noisy bins.

GD = reliability

Group-delay reliability post-weights PH persistence so that phase-coherent speech peaks are trusted more than magnitude-only, noise-like high-frequency fluctuation.

One-line thesis: DFouT supplies the spectral basis; PH identifies stable high-frequency supports; group-delay reliability selects phase-coherent speech peaks; mean-subtracted contrastive C-gating turns them into sample-specific spectral conditioning.

Method

Magnitude PH support

For each sample, compute log FFT magnitude and run 1D superlevel H0 PH. Supports are extracted at half height instead of at the full death-level component.

m_i(ω)=log(1+|FFT[x_i](ω)|),   I_i,k={ω: m_i(ω) ≥ d_i,k + α_s(b_i,k−d_i,k)}

Current main value: αs = 0.5.

GD post-weighted persistence

Magnitude PH defines the topology. Group delay only reweights each peak's persistence after PH is computed, preserving support topology while validating phase reliability.

p_eff_i,k = p_i,k · max(r_GD_i,k, 0.25)1.0

This is the v19 GD post-only design.

PH support → pole overlap

Each PH support interval overlaps the DFouT/S4D poles through a Lorentzian window, producing a pole-wise PH evidence score.

s_i,n = Σ_k p_eff_i,k · M_i,k,n

The gate acts on existing poles rather than adding new ones.

Mean-subtracted C-residue gate

A high-band contrastive score is converted into a log-gate, then the train-set mean gate is subtracted to remove the dataset-level spectral prior.

C(i)n = clip(exp(ρ(ℓi,n − μn)), gmax) Cn

Current values: ρ = 1.5, gmax = 3.0, PH params = 0.

Why C?

C changes the residue/mixing of existing modes. It asks which covered modes this sample should emphasize.

Why not A?

A/pole movement duplicates the coverage role already handled by DFouT and can destabilize the spectral basis.

Why not dt?

dt couples frequency warp and memory length, making the sign and interpretation of the intervention less clean.

Causal diagnostic

Final accuracy alone cannot tell whether PH is sample-specific. The project therefore evaluates the same checkpoint under real PH, shuffled PH, zero PH, and optionally no-PH inference.

Diagnostic modes

ModeMeaning
realUse PHi for sample xi.
shuffleUse PHπ(i) for sample xi.
zeroSet the PH residual gate to identity / zero residual.
noneUse the baseline no-PH path, when available.

How to read the pattern

This week's progress

This week reframed the project around the strongest current evidence: v19 GD post-only PH C-gating on SC35. The paper and project materials now present DFouT as the source of frequency coverage and PH as the source of reliable sample-specific high-frequency selection. The old learnable PH encoder / C-head branch is no longer the main method; it is retained as a diagnostic history showing why learnable adapters can suffer encoder rank collapse, z shrinkage, and C_head rank-1 drift. The new main method keeps magnitude-PH support topology, post-weights persistence by group-delay reliability, maps supports to DFouT poles, subtracts the train mean log-gate, and applies a zero-parameter multiplicative gate to C. v19 reaches 96.075% final test on SC35 with real PH beating both shuffled and zero PH at evaluation time. v20 remains an ablation: it preserves a real-vs-shuffle gap but nearly loses the real-vs-zero gap, suggesting that phase should post-weight persistence rather than aggressively alter the PH filtration landscape. CIFAR/sCIFAR is now written as a task-alignment negative result: flattened 1D FFT PH is not the right view for image semantics.

Hyperparameter calibration

The PH cache is dataset-specific, so the gate can be calibrated from train-set spectral and PH/GD statistics instead of hand-tuned blindly.

β from spectral slope

Fit log E(f) ≈ −γ log(1+f)+b and set β ≈ γ/2. SC35 gives γ ≈ 1.1375, so β ≈ 0.5688; current β = 0.5.

GD floor / power

Choose floor and power so PH mass retention stays around 0.65–0.85 and the median effective number of peaks stays around 8–16.

Residual scale

Choose ρ so Q95(|ρ(ℓ−μ)|) is roughly log(1.4–1.6), then set gmax so clipping remains rare.

High-band cutoff

Use pole-wise class Fisher score over PH residuals to select a cutoff. SC35 currently uses c = 0.25 with τ = 0.10.

Weak filtration λ

v20's λ = 0.25 is aggressive. Future filtration ablations should use a peak-preservation rule to pick a weaker λ, likely closer to 0.05–0.10.

Legacy diagnostics retained

The previous learnable adapter branch is no longer the main method, but it remains useful as a diagnostic history. It explained why a learnable PH encoder plus C_head can fail even when the topological signal is meaningful.

Encoder rank collapse

PointNet-style φ → maxpool → ρ MLP + LayerNorm collapsed per-sample diversity before it reached the adapter.

z magnitude shrinkage

Even after rank repair, ||z|| shrank while bias absorbed capacity, replacing per-sample signal with a global shift.

C_head rank-1 drift

The adapter W compressed diverse z vectors into nearly one kernel correction direction, motivating the move to deterministic gating.

Roadmap

  1. 3-seed SC35 v19 replication. Confirm the 96.075% single-seed result and the real > shuffle > zero diagnostic pattern under multiple seeds.
  2. Class-conditional shuffle. Compare real PH, same-class shuffled PH, and different-class shuffled PH to separate class-level spectral signatures from instance-level cues.
  3. v21 cepstral envelope/fine PH. Add source-filter evidence as an additive stream: envelope PH for formant structure and fine PH for harmonic/source structure.
  4. Weak calibrated v20 filtration. Replace aggressive λ = 0.25 with a peak-preserving λ selected from train-set PH/GD statistics.
  5. Robustness evaluation. Test whether GD-weighted PH supports improve speech robustness under noise, corruption, or spectral perturbation.
