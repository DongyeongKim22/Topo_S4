Progress detail (≤ 280 words)

This week I first stabilized the new inverse-tan normalization line by introducing a simpler baseline: one learned global λ shared across all samples. This let me test whether the normalization itself is useful before adding any sample-wise controller. On clean data, the global-λ version gave small but consistent gains on CIFAR10-gray and SC35. Using the best CIFAR checkpoint, I then ran CIFAR-10-C evaluation and saw a clearer robustness signal, with higher mean corruption accuracy and larger gains at stronger severities.

These results motivated the E0-E7 ablation series. The goal was to answer three questions in order: (1) is sample-wise control actually needed beyond a single global λ? (2) if so, does persistent homology provide useful structure for choosing λ? and (3) is a simple controller enough, or do we need a more flexible MLP? To test this, I compared raw input (E0), global learned λ (E1), PH-rule controllers using top lifetimes only and lifetimes plus peak frequency (E2-E3), PH-linear and PH-tiny-MLP Δλ heads (E4-E5), a spectrum-MLP control without PH (E6), and a shuffled-PH sanity check (E7).

The current picture is that inverse-tan normalization is useful, sample-wise control is worth pursuing, and the strongest present candidate is the low-capacity PH-Linear controller. Lifetime-only rules were too weak, adding peak location helped, and the larger nonlinear PH head did not yet beat the simpler linear readout.

Current direction

  • Treat global learned λ as the stable baseline.
  • Use PH-Linear Δλ as the current main sample-wise controller candidate.
  • Confirm the ranking with multi-seed runs and stronger sanity checks.
