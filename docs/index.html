Motivation

A working hypothesis is that near-Nyquist digital frequencies can become numerically over-sensitive under bilinear / Tustin discretization because of frequency warping. The main question is not only whether high-frequency sensitivity exists, but whether a sample-wise controller can decide when attenuation helps and when it should back off toward identity.

ω(Ω) = (2 / Δ) tan(Ω / 2),    dω/dΩ = (1 / Δ) sec²(Ω / 2)

Current method family

The repository started with dataset-level PC masks and later moved through dynamic PH masking. The current main line is now much narrower: PH-guided inverse-tan spectral normalization.

Wλ(Ω) = β + (1 - β) / (1 + λ tan²(Ω / 2))
  • Identity fallback: if λ = 0, then W = 1.
  • Targeted control: larger λ suppresses near-Nyquist components more strongly.
  • Current comparison: E0 raw, E1 global learned λ, and E4 PH-linear Δλ.

Progress

This week I consolidated the inverse-tan normalization results on RGB CIFAR and re-centered the story around a stronger baseline. The key finding is that the shared global-λ model (E1) is already a strong clean+robustness baseline: on CIFAR-10 RGB it improves test@best-dev over raw E0 and gives a clear CIFAR-10-C gain, and on CIFAR-100 RGB it also improves both clean accuracy and CIFAR-100-C mean accuracy. This shows that the inverse-tan line itself is useful before any sample-wise controller is added.

I also analyzed an initial full CIFAR-10 RGB run of the PH-linear sample-wise controller (E4). E4 reached the highest best-dev accuracy among E0/E1/E4, confirming that PH-guided sample-wise control is viable, but its test@best-dev and CIFAR-10-C mean accuracy are still below the current E1 baseline. The main issue appears to be optimization: early in training, E4 stays close to the identity regime for many epochs before moving into a more moderate λ range.

So the current conclusion is not that E4 already wins, but that E4 remains the most promising sample-wise direction while E1 is the present strong baseline. I also clarified that the current CIFAR-10 RGB implementation applies one inverse-tan profile shared across RGB channels. Next I will rerun RGB CIFAR with per-channel inverse-tan coefficients, and next week I plan to run E0, E1, and E4 on Pathfinder and additional benchmarks with three seeds.

Current interpretation

  • The inverse-tan normalization family itself is clearly useful.
  • E1 is now the strongest confirmed RGB clean+robust baseline.
  • E4 remains the most promising sample-wise controller, but its headline claim should wait for better tuning and multi-seed evaluation.
  • The current E4 gap looks more like an optimization / operating-point issue than a failure of the PH-linear idea.

Important RGB implementation detail

In the current CIFAR-10 RGB / CIFAR-100 RGB code path, the inverse-tan attenuation profile is shared across the three RGB channels for a given sample. So the current RGB results are based on a shared-across-channels inverse-tan profile, not yet a per-channel controller.

Current direction

  • Use E1 as the current strong baseline.
  • Keep E4 as the main sample-wise controller candidate.
  • Rerun RGB CIFAR with per-channel inverse-tan coefficients.
  • Run E0 / E1 / E4 on Pathfinder and other benchmarks with three seeds.
  • Keep reporting controller behavior such as λ, Δλ, pass ratio, and gradient signals alongside accuracy.
